🎬 Movie Data Analysis Project

📌 Project Overview

This project focuses on analyzing movie industry data to uncover meaningful insights into movie production, financial performance, production companies, and industry trends.

The project covers the complete data analysis workflow, starting from data collection and preparation to data cleaning, exploration, SQL analysis, and interactive visualization using Power BI.

It was developed as a collaborative project by a team of four members as part of the NTI Data Analytics Training Program.

🎯 Project Objectives

- Analyze movie production trends over the years.
- Explore revenue and budget patterns across the movie industry.
- Identify the highest-grossing and highest-budget movies.
- Evaluate the performance of production companies.
- Explore movie production distribution across countries.
- Identify the most active actors and directors.

🛠️ Tools & Technologies

- Python: Data Cleaning, Data Transformation, and Exploratory Data Analysis.
- Pandas: Data Manipulation and Processing.
- SQL: Data Querying and Analysis.
- Power BI: Interactive Dashboards and Data Visualization.
- Excel / CSV / JSON: Data Sources and Formats.

📂 Dataset Description

The project utilizes multiple datasets containing information about movies, ratings, actors, directors, production companies, and financial performance.

Main data sources include:

- Movie Metadata
- Movie Ratings
- Movie Credits (Cast & Crew)
- Movie Keywords
- Movie Links

Multiple datasets were integrated using common identifiers to create a unified analytical dataset.

🔄 Project Workflow

1. Data Understanding

- Examining available datasets and their structures.
- Understanding relationships between different tables.
- Identifying data types and potential quality issues.

2. Data Cleaning & Preparation

- Handling missing values.
- Processing JSON-formatted datasets.
- Extracting cast and crew information.
- Transforming data into structured tables.
- Preparing datasets for analysis and visualization.

3. Data Analysis

- Exploring movie production trends.
- Analyzing budget and revenue distributions.
- Investigating production companies and countries.
- Examining actors' and directors' activity.

4. Data Visualization

Building an interactive Power BI dashboard to communicate key findings and support data-driven insights.

📊 Dashboard Highlights

The dashboard includes the following analytical views:

- Movie Production Over the Years.
- Revenue Growth Over the Years.
- Top Grossing Movies.
- Highest Budget Movies.
- Top Production Companies by Total Budget.
- Top Movie Producing Countries.
- Most Active Actors.
- Most Active Directors.
